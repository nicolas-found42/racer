## Implemented adapter and candidates

Its two-entry registry pins exact source GLB and native proof hashes, exact omission sets and stock rim identities. It derives attachment outer frames from native owner chains, verifies exported matrices against native bindings, requires every native model instance in every selected part/shared-wheel resource, rejects ambient/unknown pins and unsupported geometry, mirrors Z with winding/normal/tangent corrections, preserves source BIN/image data, retains source wheel shapes and X/Z pivots, measures conservative whole rim+tire cylinders, and applies only a common ground lift. Every reachable mesh node maps to body or one of four wheels. Mustang has two shared models per wheel; Golf has three; the count derives from actual native resources rather than the 350Z layout. Explicit optional glass policy affects only exact `CarGlass`/`BlackOpaqueGlass` shaders and retains original material objects. Candidate outputs use that policy.
