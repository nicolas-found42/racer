1. P1 full vehicle import: missing assembly/material/collision context prevents diagnosing a wrong donor car from one body mesh. Accept only exact source chain + assembled dimensions/orientation/wheels + captures + collision/attachment checks. Keep material index5 unresolved.
2. P1 new event lifecycle and independent-save failures: reconstruct phase/checkpoint/reward/save/reload, including invalid/reset/retry; accept no duplicate rewards and explicit unsaved state. Domain/native valid paths observed; final expanded failure captures still pending.
3. P1 historical build retention: archive executable/source/shaders before replacing tested builds; verify manifest hashes and partial-state reporting. Earlier missing binaries stay unknown.
4. P2 livery mismatch/stalls: correlate layer state hash/revision with raster/upload and captures. Test order/opacity/cancel/reload and unavailable telemetry; qualify full32-layer render performance separately.
5. P2 runtime drift: repeat keyboard/virtual-pad, orientation and no-capture performance on integrated build; earlier passing results do not certify later renderer changes.

No codebase-wide or all-milestones completion is claimed. Each new slice must update this inventory with actual emitted/retrieved data and material limitations.
