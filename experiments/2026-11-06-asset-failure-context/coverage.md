# Asset failure context and current coverage

This is a documentation refresh of selected reviewed boundaries, not an all-codebase completion claim. The [current inventory](output/current-source-coverage.json) records 150 first-party source files: **37 have current boundary inspection credit, 28 retain prior matching-hash inspection credit, and 85 are explicitly uninspected**. Each row contains its current SHA-256, status and reason. Inspected means the named boundary was examined; it does not mean every line, branch, failure mode or runtime configuration was exercised.

## Refresh method

The inventory covers regular C/C++/Objective-C++/Python/shell source files under `src`, `scripts` and `tests`, plus `CMakeLists.txt`. Bytecode, experiment-only programs and vendor trees are outside this enumeration. Prior inspection was inherited only where the current SHA exactly matches [the earlier inventory](../2026-11-06-observability-delta/output/source-coverage-inventory.json). Changed files received credit only from a named matching-hash independent review or a focused read in this refresh. Artifact-only reviews without a code hash remain artifact evidence; they do not automatically certify the current producer.

This refresh directly read the current `car_coverage.py` input hashing and evidence joins, its eight test definitions, `preserve_build.py` selection/copy/limits, and `verify_feedback.py` frozen selection and post-run identity checks. These are read-only source inspections, not fresh test execution or an independent security certification. The JSON retains the named review records and their hashes. Sequential hash sampling is not an atomic filesystem snapshot. Current CMake inspection was not inferred from successful CTest execution.

No code, build, GPU run, catalog or shared runbook changed during this refresh. Only this document and the inventory were written. The inventory is approximately 83 KiB, below its 1 MiB cap; the leaf was approximately 28.62 MB of regular files before this document, below 32 MiB. Existing evidence is retained; no cleanup was performed.
