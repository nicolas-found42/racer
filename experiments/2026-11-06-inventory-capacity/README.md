## Verified implementation and exact scope

Shared `scripts/prepared_inventory.py` now supplies strict16MiB/3000-record metadata decoding/encoding to the four consumers. 3000 matches the existing installer record ceiling; native library already allows4096 and256KiB, so neither runtime limit was changed. The independent audit suggested2048 rows; root chose the already-existing producer ceiling3000 while retaining the independent16MiB byte cap. Real observed52 rows do not imply arbitrary3000large rows fit: either bound rejects before use. Existing single-file layout, opaque fields, exact frozen input bytes and legacy missing-schema read shape stay supported; registration still requires schema1. Duplicate keys/IDs, unknown explicit schema, invalid identities/nonfinite values and byte/count overflows reject.

Registration keeps256KiB/64 selections,128MiB actual read batch and32MiB individual mesh limits. Its peak-output admission now charges old+new inventories, selection/report, largest immutable temporary and64KiB allowance, with50.25MiB hard cap. This is a tool bound, not permission to exceed the explicit experiment/project reservation. Encoding iterates JSON chunks and checks cumulative bytes including final newline before retaining each chunk, rather than allocating the full oversized pretty result. Object graph/individual chunk/Python overhead and final join mean it is not an RSS guarantee.

The source-selection verifier no longer copies every retained/historical vehicle file. It reads a capped active catalog, locates the first exact Juiced2 source, and pins original indices0/1/2/4 into a four-entry subset (target localindex3). It snapshots only four model pairs, with64MiB selected bytes and128MiB aggregate reads including unselected scanned descriptors. Plan/sidecar retain source catalog, original indices, descriptor/source/mesh hashes, read attempts/bytes and fixed caps. Read/write context is checkpointed before each operation; plan/subset-catalog writes clear model ownership. No source-role/eligibility or active-player publication changed.

Exact reviewed source is frozen under `output/after`; pre-change bytes under `output/before`.
