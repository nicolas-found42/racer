# Project instructions

Shared lab hub: `../..` (relative to this repository root). At session start, read its `AGENTS.md` and `docs/toolchain.md`; follow their conditional tool references. Read them explicitly because this independent Git root may stop automatic parent-instruction discovery.

Read README.md (or PROJECT.md in an existing project), then experiments/README.md and the latest relevant experiment. Check Git status. When working in the lab, also read the hub AGENTS.md and its workflow/storage policies. Keep this project an independent repository.

Use experiments/<id>/README.md for every investigation, with the exact target/build/hash, bounded command, observation, evidence location, retention state, and next action. Retain canonical inputs and saved analysis state. Verify a current blocker before resuming historical work. Update the resume entry before finishing.
